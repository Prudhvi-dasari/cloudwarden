## Next backend review

These are not fixes in this phase. They are follow-ups before a production rollout of the unapplied SQL.

| Concern | Why it matters |
| --- | --- |
| Download counters count URL issuance | `claim_download_slot` increments when a signed GET URL is issued. The URL lasts 900 seconds and can be fetched many times. Owner copy now says “links issued” and “N of M links”. The recipient page, dashboard, uploads drawer, and the `DOWNLOAD_LIMIT` error say “link limit”. Public terms, security, compliance, and the API docs page no longer call that counter a download count. The JSON field name `downloadCount` is unchanged. Delivery was not rearchitected. |
| Platform reservation at 100,000 rows | On 23 October 2026 a disposable cluster with 100,000 occupied 1-byte rows reserved one more file in 107.287 ms, then in 25.491 ms, then in 54.779 ms on the Phase 4 closeout. The occupied-byte sum was a sequential scan: 76.701 ms, then 24.828 ms, then 48.638 ms. A second reservation waited on `Lock/advisory` and finished 126 ms, then 63 ms, after the holder committed. The closeout waiter was on that lock after 47 ms and also finished 63 ms after the commit. Every run stayed inside the 5 second reservation gate and the 2 second sum gate. This is not a production dump. |

## Enhancements

| Item | Note |
| --- | --- |
| Account quota and paid 300 GB / 365 day plans | `paidFeaturesEnabled` is false. Do not enforce a paid quota until the server can verify an entitlement. |
| Global storage ledger | The platform cap is a locked sum of occupied rows, not a second counter and not `canReserve`. The repository constant is `1000000000000` for the whole platform, not a per-user quota. Production still enforces `300000000000` until the new migration is applied. |
| Prerendered marketing HTML | Public routes are client-rendered. Search engines can see titles from `index.html` and `SeoHead`, but body copy depends on JavaScript. |
| Upload pause | `UPLOADS_PAUSED` blocks new reservations and new part URLs. It does not revoke a URL already signed. Completion, download, delete, and cleanup stay available. It is not set in `wrangler.jsonc`. |
